# Day 01 – My 90-Day DevOps Learning Plan

## Where I'm starting from
- 4+ years in operations and process-driven roles (Genpact, Bandhan Bank and others)
- Since July 2022: self-directed switch into Salesforce Administration and AWS Cloud/DevOps
- Certifications include AWS Certified DevOps Engineer – Professional, Salesforce Platform Administrator I & II, Platform App Builder and GitHub Actions

## What DevOps means to me
- Shipping changes safely and often by automating builds, tests and deployments
- Owning what you ship: monitoring it, and fixing it when it breaks
- Dev and Ops working toward the same goals, with shared pipelines and feedback
- **Cloud engineering**: infrastructure that is reproducible, scalable and defined as code

## Why I'm doing this
Certifications show what I know. These 90 days are about showing what I can build and troubleshoot, one commit at a time.

## 3 goals for the next 90 days
1. Finish all 90 days, with a commit and a blog post for each day
2. Build 3–4 real end-to-end projects: CI/CD, Docker + Kubernetes, Terraform on AWS, monitoring
3. Become interview-ready for Salesforce Admin, CRM/DevOps support and junior DevOps/Cloud roles

## 3 core skills to build
1. Linux and shell scripting: confident troubleshooting from the terminal
2. CI/CD and containers: GitHub Actions, Jenkins, Docker, Kubernetes
3. Infrastructure as Code on AWS: Terraform, plus observability with Prometheus and Grafana

## Weekly time commitment
- About 2 hours a day (roughly 14 hours a week)
- Weekdays: the daily task and blog post. Weekends: catching up and revising.

## How I'll stay consistent
- Learning in public on Hashnode and LinkedIn every day
- On a bad day, I do the smallest useful version of the task instead of skipping it
- Writing down what broke and how I fixed it
